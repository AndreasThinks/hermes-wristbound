Hermes

Send messages to Hermes from Index and Pebble apps. Connects directly to your self-hosted Hermes dashboard. No Wristbound companion or Telegram account needed.

Sign in

Use your dashboard HTTPS address, not the Hermes API port. Password sign-in requires a dashboard with Pebble-compatible native sign-in.

Destination

To start fresh from Index, say “New Hermes session, then …” followed by your message. Name a chat to send there once.

Hermes speaks its reply to each message you dictate, like /voice, and Wristbound offers Play. Other messages in the chat stay text. Needs the wristbound-voice plugin on your Hermes; without it, messages are sent as text.
